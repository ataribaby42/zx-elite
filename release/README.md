# ZX Spectrum Elite

`elite-128k.tap` is the playable tape image rebuilt from this project's
assembly sources. Optional fixes and modifications depend on the build
settings used.

Despite its name, **Elite 128K is a 48K program** with compatibility fixes
for 128K machines. It does not use expanded memory.

## Running the game

1. Set your ZX Spectrum emulator to **48K mode**.
2. Open `elite-128k.tap` using the emulator's tape autoload feature.
3. Alternatively, attach the tape, enter `LOAD ""` in BASIC and start tape
   playback.
