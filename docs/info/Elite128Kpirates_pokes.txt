Seeing as the Dread Pirates Red pitched up on the stream today, I’ve reread the World Of Spectrum forum post by Ersh regarding them - once you’ve got them, you’re stuck with them :(

They list two POKEs to turn them off:
48k - POKE 56907, 254
128K - POKE 55315, 254
They’ve also made a list of 12x POKEs to enter which is essentially a mod for the 128k version - if you approach a Station and it isn’t rotating (denoting that pirates have overtaken it) then you can jump to another system to escape. Clever stuff!


Pirate's will never board your ship 128k:

poke 55315,254

Pirates board your ship every time 128k:

poke 55310,0

I forgot to mention that the pirates event, like the missions, never happen in the first galaxy. So if you're still in galaxy 1 you also need to enter (48k: poke 53349,1) or (128k: poke 43047,1) if you just want to see the boarding. Remember that you need to hyperspace jump in order to activate it too.

I checked the corrupt police in the 128k version and they had already fixed it so no pokes needed there.

I had to find a few free bytes to stick the mod into. In the 128k version there was at the end of a page and below a RET a few 0's with next entire page having the interrupt vector table so I stuck it in between there. The code doesn't access the addresses directly either so I think it's safe. Now you can hyperspace out of a system, if you notice that the station isn't rotating, then safely dock at the next system. I tested that it works, also flew around for awhile to see if anything overwrote the mod but it seems safe.
